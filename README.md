# EasyFormat - 公众号 AI 智能排版助手

[EasyFormat](https://easyfomat.cn) 是一款面向微信公众号创作者、自媒体作者、企业新媒体团队和内容运营者的 AI 智能排版工具。它可以理解文章结构，自动生成适合微信公众号后台粘贴发布的图文排版，帮助创作者减少手动调字号、间距、颜色和图片位置的时间。

> 官网：<https://easyfomat.cn>

## EasyFormat 解决什么问题

微信公众号文章排版经常需要在写作完成后重复处理标题层级、重点标注、引用、分隔线、图片位置和移动端显示效果。EasyFormat 的目标是把这些重复工作交给 AI，让创作者专注在内容本身。

适合这些场景：

- 公众号文章排版
- 微信图文排版
- 自媒体文章美化
- AI 文章排版
- 微信公众号编辑器辅助
- 企业新媒体内容生产
- 知识博主长文发布

## 核心能力

- **AI 语义级排版**：根据文章内容自动识别标题、重点、引用、列表和段落结构。
- **多种排版风格**：支持科技、极简、深度报道、知识卡片、文艺书信等多种内容风格。
- **图文混排处理**：保留图片位置，降低复制到公众号后台后的错位风险。
- **微信后台兼容**：生成适合粘贴到微信公众号后台的内联样式 HTML。
- **一键复制发布**：预览后复制到公众号后台，减少二次调整。

## 使用方式

1. 打开 [EasyFormat 官网](https://easyfomat.cn)。
2. 粘贴公众号文章草稿，支持纯文本、Markdown、从 Word 或 Notion 复制的内容。
3. 选择适合文章调性的排版风格。
4. 点击 AI 排版，预览生成结果。
5. 一键复制到微信公众号后台发布。
